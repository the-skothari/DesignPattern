# Low-Level Design (LLD)

This repository contains my learning and implementation of **Low-Level Design (LLD)** concepts, focusing on writing clean, maintainable, scalable, and extensible code.

The goal is to understand important software design principles and apply them through practical Java implementations.

## Topics Covered

### SOLID Principles

SOLID is a set of five design principles that help developers write better object-oriented software.

| Principle | Description | Status |
|---|---|---|
| **S** - Single Responsibility Principle (SRP) | A class should have only one reason to change. | Completed |
| **O** - Open/Closed Principle (OCP) | Software entities should be open for extension but closed for modification. | Completed |
| **L** - Liskov Substitution Principle (LSP) | Subtypes should be replaceable for their base types. | Upcoming |
| **I** - Interface Segregation Principle (ISP) | Clients should not be forced to depend on methods they do not use. | Upcoming |
| **D** - Dependency Inversion Principle (DIP) | High-level modules should depend on abstractions, not concrete implementations. | Upcoming |
